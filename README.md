## 👋 About

I left my job in March 2026 to build **DocuFast India**, a document convenience platform for passport, PAN, Aadhaar, driving licence and voter ID services, plus printing, scanning and lamination with doorstep delivery.

I run the business **and** build the product: the customer app, payments, admin tools, a print-shop desktop agent and an Android app.

- 🏢 Operating from Mahabubnagar, Telangana, India
- 🎯 Open to **Technical Product Manager** and **Founding / Full-Stack Engineer** roles
- 🌱 Learning: system design, safe refactoring (characterization tests, strangler fig, feature flags)

## 🚀 Projects

| Project | What it does | Stack |
|---|---|---|
| [**DocuFast India App**](https://github.com/syedfayazali/docufast-app) | Customer web app + Android app: apply for services, upload documents, pay, track status, book appointments, get push alerts. Admin panel for applications, payments and orders. | React, Vite, Tailwind, Supabase, Razorpay, Brevo, Web Push |
| [**DocuFast Print**](https://github.com/syedfayazali/Docufast) | Upload a PDF, pay online, and it prints automatically at a partner shop. Owner dashboard with revenue and printer health. | Next.js 14, PostgreSQL, Vercel Blob, Razorpay |
| [**DocuFast Agent**](https://github.com/syedfayazali/Docufast-Desktop) | Windows tray app that polls the cloud for paid jobs and prints them. Auto-start, auto-update, one-click installer. | Electron, Node.js, GitHub Actions |
| [**Pathfinder**](https://github.com/syedfayazali/pathfinder) | Job application tracker with Kanban pipeline, contacts, documents, resume builder and AI email scanner. | React 19, TypeScript, Supabase, Tailwind 4 |

<details>
<summary><b>How the DocuFast platform fits together</b></summary>

<br>

- **Security first:** prices, payment status and roles are enforced in the database (Row Level Security + triggers) and on the server, never trusted from the browser
- **Payments:** Razorpay with server-side signature verification, a webhook fallback and a manual UPI proof flow
- **Reliability:** automatic print retries, stuck-job detection, device heartbeats, scheduled cleanup of abandoned uploads
- **Privacy:** customer files are removed after printing or when checkout is abandoned

</details>
